为什么做这个产品

类型代表问题
传统排盘网站某果网、某子平堆术语、广告多、UI 停留在 2010 年。排出来的四柱看不懂
AI 算命 app某小算、某大师要付费、要注册、不透明。AI 怎么得出结论的——完全黑盒

FateCipher 的差异化

  • ✓ AI 深度思考可见：前 6 段结构化推演全部展示，最后给大号行动建议
  • ✓ 数据不出浏览器：八字/紫微排盘本地引擎，AI API 只接收排好的四柱，不碰原始数据
  • ✓ 四种玩法一个入口：八字、紫微、塔罗、AI 问答——首页直接露出
  • ✓ 免费 + 无注册门槛：首页八字直接排、塔罗直接抽。建档才需要 signIn

产品定位与功能定义

一句话定位

FateCipher = 命理工具 + AI 老师傅。用八字 / 紫微 / 塔罗把出生数据结构化成「命盘」，再用 AI 把命理语言翻译成人话。

四大玩法

玩法输入输出
八字测算出生日期 + 时辰四柱排盘 + 五行分析（本地引擎）
紫微斗数出生日期 + 时辰 + 性别紫微命盘 + 十二宫解读
塔罗占卜一个问题 + 抽牌三张牌阵解读
AI 问答你的困惑AI 回答 + 深度思考推演

四玩法排序 rationale

  • 八字排第一：对"我到底是什么命"的原始需求最直接
  • 塔罗排第二：门槛低（不需要精确时辰）
  • 紫微排第三：排盘最复杂，给老用户
  • AI 问答排最后：消费型工具，依赖前面几个玩法先帮用户建档

从 0 到 1 核心路径

v0.0 项目初始化（一个周末） ├─ Next.js 脚手架 + Tailwind v4 + shadcn/ui ├─ 首页 Hero + 四玩法骨架页面（空壳路由） └─ 八字本地排盘引擎（关键：四柱 + 五行） v0.1 功能优化（一个晚上） ├─ AI 问答深度思考重构（前 6 段推演 + 大号行动建议） ├─ 导航栏 UI 优化（4 入口直接露出） └─ 品牌名全局替换（xuanji → fatecipher）

核心经验

  • • 本地存储 + 抽象层是 0→1 最优解：API 层对齐，未来接后端无痛迁移
  • • AI 深度思考 = 差异化：市面产品只给结果，我们让用户看到推演过程
  • • 品牌设计要调性统一：紫色（神秘+科技）+ 宋体（传统）+ 无衬线（现代）
  • • 四玩法不做二级菜单：只有 4 个，直接露出 = 降低决策成本
  • • SSE 流式是必须的：比 loading spinner 体验好 10 倍
v0.2 新增功能 · 用户命盘档案管理 commit 35074fc · 2026-09-09

为什么新增档案管理

#场景发生了什么
P0多账号串数据用户 A signIn 建档 → signOut → B signIn 看到 A 的档案。旧 key fatecipher.profile.bazi 是全局的
P0额度也串了AI 问答 5 次额度旧 key 也是全局，A 用完 → B 显示"0 次"
P1四种玩法各填一次八字要填、紫微也要填、AI 问答想个性化还要再建一次
P1不能编辑/删除填错出生时间？没法改

一句话：v0.1 跑出了产品价值，但用户数据没有"归属"——属于谁、用在哪、能不能改，全没有。档案管理就是给用户数据加归属。

用户故事

#用户故事验收要点
US-01作为已登录用户，我希望保存命盘档案，这样四种玩法共用出生信息建档后，八字/紫微/AI 问答三页都检测到"档案已保存"
US-02作为已登录用户，我希望 AI 问答结合我的档案回答，这样更有针对性AI 回复引用"你的命盘日主干支"
US-03作为用户 A，我希望用户 B signIn 时看不到我的档案key 隔离：fatecipher.profile.{email}
US-04作为建档用户，我希望能编辑/删除档案/profile 三态完整

详细方案

M1 ProfileStore（src/lib/profile.ts）

API职责
getProfile(email)读 fatecipher.profile.{email}，不存在返回 null
saveProfile(email, data)写 fatecipher.profile.{email}，自动加 createdAt/lastUpdated
deleteProfile(email)删 key
migrateFromLegacy(email)读旧 key → 搬 → 删旧 key。新 key 已存在则跳过
getQuota(email) / consumeQuota(email)额度按 email 分账

M2 /profile 档案管理页

AuthGuard 包裹。四态：

  • • 空态：标题"还没有命盘档案" + 双 CTA（去八字 / 手动建档）
  • • 详情态：字段展示 + 编辑/删除按钮
  • • 编辑态：出生日期/性别/时辰/出生地 + 保存/取消
  • • 删除：confirm 弹窗 → 二次确认 → 回空态
