PRD 写作规范

FateCipher 多版本 PRD 的统一格式约定。v0.3+ 直接按这个来。

一、目录结构

d:\FateCipher\用户命盘档案管理\
├── PRD.html              ← 唯一的 HTML（所有版本在这一个文件里）
└── assets\               ← 所有截图
    ├── v01-xxx.png       ← 前缀 = 版本号两位 + 连字符 + 描述
    ├── v02-yyy.png
    └── v03-zzz.png       ← 未来 v0.3 的截图

新增版本时：

  1. 不新建目录，继续往 assets/ 里丢截图，前缀改一下就行
  2. 不新建 HTML，继续往 PRD.html 里追加版本 section

二、14 个标准子章节（每个版本固定这 14 个）

#章节名回答什么问题配什么视觉元素
一项目相关人员谁来做？一个人分饰几个角色？人员表（角色/姓名/职责）
二项目开发排期花多长时间？几个 commit？阶段表（阶段/周期/commit/产出）
三项目背景为什么要做？v0.X 里暴露了什么问题？痛点表（P0/P1 分级）+ 一句话卡片
四项目目标这次要达成什么？目标表（带 pill 状态）或 clean list
五目标用户谁会用这个新功能？用户故事？用户画像表 / 用户故事表（US-01, US-02...）
六竞品分析与方案选型为什么选这个技术？为什么不那样做？竞品对比表 + 技术选型表 + 1-2 个"为什么"段落
七设计思路UI 怎么想的？key 怎么分？状态怎么切？Key 映射表 / 排版决策表 + 截图
八核心功能详细说明API 长什么样？页面有几态？API 表 / 状态表 + 低保真流程图 + 运行截图（shot-grid 或 shot-pair）
九数据埋点需要埋哪些事件？事件表（事件名/触发时机/状态）
十完整主流程图功能的完整路径从哪到哪？CSS 低保真 .lf 流程图（菱形决策 + 圆角起止 + page 占位）
十一系统交互时序图核心交互的时序细节？ASCII .diagram 时序图（User → 组件 → API）
十二异常流程与规则出错怎么办？边界怎么处理？异常表（#/场景/处理），E1/E2 编号
十三验收标准怎么算做完了？验收表（项/结果 ✅），分组列（多账号隔离/自动迁移/...）
十四迭代规划下一个版本做什么？版本链表（版本号/内容）

    五、CSS 组件速查

    Class用途v0.1/v0.2 示例
    .v-banner版本切换横幅（灰底 + 版本 badge + 标题 + commit 日期）两个版本之间都有一条
    .section-no章节前的中文序号（紫色等宽）<span class="section-no">一</span>
    .card白底圆角卡片（装表格/列表）用得最多的容器
    .shot-box截图容器（带 caption）单张图
    .shot-pair2 列并排图低保真 + 运行截图对照
    .shot-grid自适应网格（auto-fit, minmax 250px）三态截图
    .lf低保真流程图容器（CSS 画的）档案生命周期 / signIn 迁移
    .diagram暗色等宽代码块（ASCII 时序图）AI 问答 SSE / 迁移时序
    .pill彩色状态标签okskyskwarn
    .clean无序列表（padding:0）干净的项目符号
    .v-groupsidebar 版本组标题（可展开收起）带 arrow 指示器
    .v-badgesidebar 版本号标签（紫/蓝）v0.1 紫色 / v0.2 蓝色

    六、版本写作 Checklist

    每次写完一个版本，核对这 8 项：

    • ✅ sidebar 里 data-group-children="v{NN}" 的 li 数量 = 14 个
    • ✅ 正文 section id 全部能被 sidebar 链接到（点一下能跳）
    • ✅ 每个 section 的 h2 都有 <span class="section-no">一</span>
    • ✅ 中文序号一~十四在 sidebar 和正文完全一致
    • ✅ Banner 里的 commit hash 指向真实 commit
    • ✅ 截图文件名以正确版本号开头（v03-xxx.png）
    • ✅ 至少一张低保真 .lf 流程图（第十章）
    • ✅ 至少一张 ASCII .diagram 时序图（第十一章）

    七、版本分组颜色约定

    版本类型sidebar v-badge 颜色banner vb-badge 颜色
    从 0 到 1 项目.v-badge 紫色（默认）.vb-badge 紫色（默认）
    新功能 / 基础架构.v-badge.v02 蓝色.vb-badge.v02 蓝色
    小修复 / 补丁灰色（新增 .v-badge.v03）灰色

    CSS 加颜色只要新增一条：.v-badge.v03 { background: #fef3c7; color: #92400e; }（warning 黄）
